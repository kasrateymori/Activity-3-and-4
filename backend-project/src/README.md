# فعالیت فصل چهارم: کانتینرسازی پروژه بک‌اند با Docker

## ۱. توضیحات پروژه

هدف این فعالیت، کانتینرسازی (Containerization) یک پروژه بک‌اند با استفاده از Docker و Node.js است.

در این پروژه با ایجاد فایل‌های Dockerfile و .dockerignore، نحوه آماده‌سازی پروژه برای ساخت یک Docker Image و اجرای آن در قالب یک Container بررسی می‌شود.

## ۲. فایل Dockerfile

فایل Dockerfile شامل دستورالعمل‌هایی برای ساخت یک Image از پروژه Node.js است.

محتویات فایل:

```dockerfile
FROM node:20

WORKDIR /app

COPY package*.json ./

RUN npm install

COPY . .

EXPOSE 3000

CMD ["npm", "start"]
```

توضیح دستورات:

- **FROM:** انتخاب تصویر پایه Node.js.
- **WORKDIR:** تعیین مسیر کاری داخل کانتینر.
- **COPY:** کپی کردن فایل‌های پروژه به داخل کانتینر.
- **RUN:** اجرای دستور نصب وابستگی‌های پروژه.
- **EXPOSE:** مشخص کردن پورت مورد استفاده برنامه (3000).
- **CMD:** تعیین دستور اجرای برنامه هنگام شروع کانتینر.

## ۳. فایل .dockerignore

این فایل برای جلوگیری از انتقال فایل‌های غیرضروری به محیط ساخت Docker استفاده می‌شود.

محتویات فایل:

```text
node_modules
.git
.env
npm-debug.log
```

## ۴. ساخت Docker Image

برای ساخت یک Image از پروژه، دستور زیر استفاده می‌شود:

```bash
docker build -t node-backend .
```

در این دستور:
- `docker build` برای ساخت Image استفاده می‌شود.
- `-t node-backend` نام Image را مشخص می‌کند.
- `.` مسیر پروژه فعلی را به‌عنوان Build Context مشخص می‌کند.

## ۵. اجرای Container با Port Mapping

برای اجرای کانتینر و اتصال پورت آن به پورت سیستم، از دستور زیر استفاده می‌شود:

```bash
docker run -d -p 3000:3000 --name my-backend node-backend
```

توضیح پارامترها:

- `-d`: اجرای کانتینر در پس‌زمینه.
- `-p 3000:3000`: اتصال پورت 3000 سیستم به پورت 3000 کانتینر.
- `--name my-backend`: تعیین نام برای کانتینر.
- `node-backend`: نام Image مورد استفاده.

## ۶. خروجی مورد انتظار

پس از انجام مراحل، خروجی مورد انتظار شامل موارد زیر است:

- ایجاد یک Docker Image با نام `node-backend`.
- اجرای یک Container با نام `my-backend`.
- دسترسی به برنامه از طریق پورت 3000.

## ۷. نتیجه‌گیری

در این فعالیت، نحوه کانتینرسازی یک پروژه بک‌اند با استفاده از Docker بررسی شد. با استفاده از فایل Dockerfile، دستورالعمل‌های ساخت Image مشخص شدند و فایل .dockerignore برای حذف فایل‌های غیرضروری مورد استفاده قرار گرفت.

همچنین دستورات لازم برای ساخت Docker Image و اجرای Container با استفاده از Port Mapping معرفی شدند.
